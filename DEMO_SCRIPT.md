# Demo Script — SOC 2 Compliance Sandbox
**Marineso Inc. · Платформа автоматизации SOC 2 аудита**

> Время демо: ~25–30 минут  
> URL: http://localhost:8080  
> Логин: admin@acme.com / admin123

---

## Контекст для клиента (вступление, 2 мин)

> "Мы покажем платформу, которая автоматизирует весь цикл SOC 2 Type II подготовки — от сбора evidence до генерации политик и финального отчёта для аудитора. Всё что раньше занимало недели ручной работы — здесь делается за минуты."

**Проблема которую решаем:**
- Подготовка к SOC 2 вручную: 3–6 месяцев, команда из 5+ человек
- Evidence собирается руками из AWS, GitHub, Okta, HR-систем
- Аудиторы тратят дни на проверку разрозненных документов
- Политики пишутся с нуля для каждой компании

**Что делает платформа:**
- Автоматически собирает evidence из всех источников через агентов
- В реальном времени показывает статус каждого из 33 SOC 2 контролей
- Генерирует черновики политик через AI за минуты
- Даёт аудитору готовый портал с комментариями и evidence

## Блок 1 — Dashboard (3 мин)

**Откройте:** http://localhost:8080 → войдите

**Покажите:**
- Сводный дашборд: сколько контролей PASS / FAIL / UNKNOWN

- Секция Agents в левом меню — точки входа для автоматизации

> "Это живой дашборд. Каждый раз когда агент собирает новые данные — статус обновляется автоматически. Здесь видно текущее health компании с точки зрения SOC 2."

## Блок 2 — Automated Agents: сбор evidence (8 мин)

**Откройте:** Dashboard → секция **Agents** в меню

Объясните концепцию: каждый агент подключается к реальной системе, собирает данные, сохраняет их как evidence, обновляет статус контролей.

### 2a. AWS Scanner (2 мин)
**Нажмите Run** на AWS Scanner

В терминале покажите:
```
Scanning S3 buckets...
Scanning IAM users...
Scanning EC2 instances...
Scanning CloudTrail...
```
> "Агент смотрит на AWS: есть ли шифрование на S3, правильно ли настроен IAM, включён ли CloudTrail. Каждая проверка — это evidence для аудитора."

### 2b. HR Agent (2 мин)
**Нажмите Run** на HR Agent

В терминале показывает violations:
```
CC6.2 FAIL — offboarding incomplete
CC1.4 FAIL — missing training
```
> "HR агент сравнивает список сотрудников в Okta с HR-системой. Видит уволенных с активными аккаунтами, людей без обязательного обучения. Это прямые findings для аудита."

### 2c. Policy Generator (3 мин)
**Нажмите Run** на Policy Generator

Пока генерируется (в реальном времени в терминале):
```
[AI] Generating policy for CC1.1: Information Security Policy...
[AI] Policy saved to Evidence Tracker: CC1.1
[AI] Generating policy for CC1.2: Corporate Governance Policy...
```
> "AI агент на основе данных вашей компании — GitHub репозиторий, AWS окружение, Okta домен — генерирует черновики всех 12 governance политик. Это 50–80 страниц документации которую юрист потом доводит за 1 день вместо 3 недель."

## Частые вопросы

**Q: Это работает с реальным AWS, а не LocalStack?**
> Да — LocalStack используется в sandbox. В production переключается одной переменной `AWS_USE_LOCALSTACK=false`.

**Q: Можно интегрировать с нашей HR-системой?**
> HR Agent сейчас интегрирован с Okta и BambooHR. Любая система с API добавляется за 1–2 дня.

**Q: Насколько безопасны данные?**
> JWT-аутентификация, tenant isolation (каждый клиент видит только свои данные), все API под авторизацией.

**Q: Сколько времени на развёртывание?**
> Docker Compose: `docker compose up` → готово за 5 минут.
